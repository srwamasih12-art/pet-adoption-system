# Pet Adoption System

A web-based system that helps animal shelters list pets and lets adopters browse, search, and apply to adopt them.
Software Engineering Group Project — Soran University.

## Team
| Name | Role |
|---|---|
| Member 1 | Requirements / Documentation |
| Member 2 | System Design / Architecture |
| Member 3 | Frontend / UI |
| Member 4 | Backend / Database |
| Member 5 | Testing / Quality |

## Features (core scope)
- User registration and login (Adopter, Shelter Staff, Admin)
- Browse and search pets (type, breed, age, location)
- Shelter staff add/edit/remove pet listings
- Adopters submit adoption requests
- Staff approve or reject requests
